# Jradiostudio

Build a radio automation app for remote presenters that can pull music files from AzuraCast, with the mixer on a VPS so presenters can broadcast simultaneously (AzuraCast is external, not on the same VPS). Build the presenter studio, starting with the DJ console layout and AzuraCast music browser.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://jradiostudio.lovable.app
